## 4. Rules

- Same name, website, phone and location on every single listing. No variations
  ("DevEdge Pty Ltd", "Dev Edge", a different phone number) because that weakens
  the signal.
- No prices on any listing. Everything is quoted privately.
- Only DevEdge work in portfolios: DeckMate, Tennantly, Woodhouse, TPD Timber,
  WoodEvo (website and systems only). Never Kim Hilton Studio, Lockd75 or NLB Built.
- Don't name WoodEvo as a marketing result until after December 2026.
- Use a password manager for every login, and turn on two-factor sign-in.
- Reviews: Google first. Once you have a few, ask happy clients for Clutch too.
